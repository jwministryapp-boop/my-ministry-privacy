1. 開始分頁與即時傳道計時器

精確記錄傳道時間（08:04:08），一鍵暫停或儲存至報告，記錄聖經課程數量、選擇學生並加上地區備註。

屬靈習慣與進度環

追蹤每日、每週與每月屬靈習慣（每日經文、閱讀聖經、聚會預習、家庭崇拜），一鍵在 JW Library 開啟每日經文，並可自訂個人習慣。

聖經閱讀計畫表

互動式聖經66卷書網格，提供5種閱讀路線（經典、年代順序、先讀福音書、均衡穿插、先讀短卷）、預計完成日期及 JW Library 快速跳轉。

2. 聖經學生管理

記錄每位學生的姓名及目前研讀的書刊、課次與小節（例如：《永遠享受美好的生命！》第24課第3節）。

3. 月度報告與服務年度總覽

切換服務年度（2025–2026、2026–2027），掌握年度總時數與剩餘時數，並在每月1日輕鬆分享報告。

4. 先驅日曆與時數目標進度

設定正規先驅（50小時）、輔助先驅（15/30小時）或個人月度目標，直觀比較計畫與實際傳道時數。

5. 地區卡與逐家逐戶記錄

附上地區地圖照片，篩選地址並記錄每次拜訪狀態（「初次拜訪」、「不在家」、「拒絕」）與門戶備註。

6. 設定、提醒與 iCloud 雲端備份

開啟每月1日20:00繳交報告提醒與續訪通知，並透過右上角雲端按鈕將完整資料備份至 iCloud Drive。

7. OLED 深色模式（計時器）

適合傍晚傳道並節省 OLED 螢幕電量的高對比深色主題。

8. OLED 深色模式（設定）

完美支援 iOS 系統淺色與深色外觀切換。

常見問題 (FAQ)

JW Ministry 如何與官方 JW Library 搭配使用？

官方的 JW Library 用於研讀聖經、出版物與聚會資料；而 JW Ministry 則專注於個人傳道記錄：計時器計算時數、規劃先驅時間表（15、30、50小時）、管理個人地區不在家記錄以及追蹤聖經學生進度。

我的傳道報告與地區筆記儲存在哪裡？

100% 儲存在您個人的 iPhone 或 iPad 裝置記憶體內。本應用程式沒有外部伺服器，絕不會上傳您的任何個人筆記。

更換新 iPhone 時如何轉移資料？

打開「設定」分頁，點擊右上角的雲端上傳圖示，將完整備份檔（包含地區照片）存至 iCloud Drive，然後在新手機上一鍵還原即可。

傳道時沒有網路連線也能使用嗎？

可以！所有計時器、地區地圖、大樓記錄與聖經學生筆記皆可 100% 離線運作。
